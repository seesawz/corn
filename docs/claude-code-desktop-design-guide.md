# Claude Code Desktop 风格 · corn 项目设计指南

本指南用于 corn 的项目导航、新建与重命名流程。它是本项目的设计约定，不是 Anthropic 官方桌面端组件规范。

## 参考与适配

- [Claude Code Desktop 官方产品介绍](https://claude.com/resources/articles/claude-code-desktop-redesign)：以侧边栏组织工作，并支持按项目分组。本项目采用“左侧项目、右侧任务”的结构。
- [Anthropic 官方品牌资源](https://github.com/anthropics/skills/blob/main/skills/brand-guidelines/SKILL.md)：参考暖白、墨色、灰色与赤陶橙的配色。品牌文档的字体规则主要面向品牌内容，本项目统一使用本地加载的 Noto Sans SC 可变字体。
- 下文的尺寸、行内布局、按钮层级和交互是针对本应用制定的设计决定，不声称逐像素复刻 Claude Code Desktop。

## 视觉原则

安静、清晰、紧凑。让项目名称与任务内容占据视觉中心，以间距和文字层级区分功能。赤陶橙用于小范围选中与聚焦状态，避免把每个按钮和计数都做成橙色胶囊。

**尽量减少弹窗，优先在操作发生的位置完成编辑。** 日期选择允许使用锚定按钮的轻量 Popover；项目新建与重命名继续行内完成。 新建、重命名、筛选等轻量操作使用行内输入或局部展开，保持项目与任务可见。只有需要多步操作、复杂配置或不可逆操作确认时才考虑弹窗。

新建项目从分组标题旁进入，在标题下方出现输入行；重命名直接替换原项目行。不要把编辑表单挂在侧边栏底部，不添加装饰插画、大图标或无关字段。

## 基础令牌

沿用 `uno.config.ts` 的主题变量，所有新增控件同时适配浅色和深色。

| 用途 | UnoCSS 主题变量 / 工具类 |
| --- | --- |
| 页面底色 | `--bg`，浅色 `#FAF9F5` |
| 侧边栏 | `--panel`，浅色 `#F0EEE5` |
| 输入表面 | `--card` |
| 正文 / 次级 / 辅助 | `--text` / `--text-2` / `--text-3` |
| 品牌强调 | `--accent`，`#D97757` |
| 选中背景 / 聚焦光圈 | `--accent-soft` / `--shadow-focus` |
| 边框 / 悬停 | `--border` / `--hover` |
| 主按钮 | `--text` 底色、`--bg` 文字，跟随主题反转 |
| 间距 | 4、8、12、16、24、32 px |
| 圆角 | 项目行和编辑容器 8 px，图标按钮 6–8 px |
| 线条图标 | 统一 SVG，16 px，1.6–1.8 px 描边；不使用字符充当图标 |

控件正文使用本地加载的 Noto Sans SC 可变字体，13–14 px。分组标题和说明为 12–13 px。主内容标题与侧边栏项目名使用相同字体，字重为 600；行内编辑不重复添加大标题。字体按字符范围分片加载，由本站提供 WOFF2 文件，使用 SIL OFL 1.1 授权。

## 项目导航

- 分组标题“项目”位于列表上方；右侧为带线条加号的“新建”按钮，点击范围不小于 32 px 高。
- 项目行保持至少 38 px 高，以自选图标、项目名称、未完成数和重命名入口组成一行。
- 选中背景覆盖整行，采用淡品牌色；计数采用低对比纯文字与等宽数字，不单独抢占视觉中心。
- 项目名称过长时省略，完整名称通过 `title` 提供。
- 重命名采用 SVG 铅笔图标，桌面端在悬停、键盘聚焦时显示；触屏设备持续显示。
- 键盘聚焦必须可见，不以悬停作为唯一使用方式。

## 新建 / 重命名行内编辑

- 新建输入行紧接项目分组标题，位于已有项目上方；重命名输入行替换目标项目行，不改变它在列表中的位置。
- 两种操作共用紧凑编辑组件，宽度跟随侧边栏；手机上占据项目导航完整一行。
- 新建和重命名输入行与项目导航保持相同高度与图标、文字对齐；背景透明，不增加独立卡片、外框或阴影，保留项目原有选中状态。
- 一行依次显示文件夹图标、名称输入、确认与取消按钮，输入区可伸缩且不会挤出容器。
- 确认使用无底色的品牌色勾选图标，取消使用低对比关闭图标。按钮具备说明标签与快捷键提示。
- 不在输入行下方添加辅助文字，不添加描述字段、重复标题或预览区；快捷键通过按钮提示提供。

## 项目图标

- 提供文件夹、工作、生活、开发、学习、灵感、兴趣和目标 8 个统一线条图标，使用本地 SVG 路径。
- 新建或重命名时点击左侧图标，在当前行下方展开选项；已有项目也可以直接点击图标进入选择。
- 选项区域透明，不添加弹窗、浮层或独立背景；选中图标使用局部品牌色高亮。
- 选择图标后收起选项并返回名称输入，按 Enter 或勾选按钮保存；取消时放弃名称与图标修改。
- 图标与名称一起本地保存和云同步；旧项目缺少图标时迁移为文件夹。

## 任务列表

- 使用开放式列表与细分隔线，不套厚重白色卡片、大圆角或阴影。
- 每行采用 18 px 圆形勾选框、任务名称和右侧操作，统一垂直中线；名称是视觉中心，长文本自然换行。
- 默认只显示低对比的月 / 日记录，完整时间通过提示与行内详情保留。标签和手动记录日期使用小号纯文字。
- 项目名已在页面标题中体现，不在每条任务上重复显示项目下拉框。
- 星标和详情按钮在悬停或键盘聚焦时显示，触屏持续显示。
- 点击省略号在当前任务下方展开创建 / 完成时间、移动项目和删除操作；不使用弹窗。
- 到期时间通过日期按钮旁的 Popover 编辑，提供快捷日期和月历；选中日期用实色圆形背景，今天用品牌色文字标示，具体规则见日期选择章节。
- 已完成任务使用低对比细删除线，仍保留在项目内；详情和列表继续使用 Motion for Vue 动画。

## 列表内添加任务

- 添加入口是任务列表容器内的最后一行，采用约 48 px 高的轻量输入行，与任务共用列表区域、分隔线和左侧图标对齐。空项目的提示与添加行也保留在同一个容器中。
- 不使用大圆角白色卡片、阴影和对话式发送箭头。添加行没有独立外框、圆角或外部间距；由上一行的分隔线划分，聚焦后只轻微改变背景。
- 左侧为细线加号，占位只写“添加任务…”，当前项目由页面标题交代，完整归属通过可访问名称提供。
- 空输入右侧显示低对比 Enter 提示，输入内容后显示紧凑的“添加”按钮；支持 Enter 连续添加。
- 日期、优先级和标签解析提示留在输入行下方，不使用弹窗。提交后继续聚焦输入框。

## 交互与可访问性

- 编辑时项目列表与右侧任务保持可见、可用，没有模态焦点约束。
- 双击项目名称或点击铅笔图标进入重命名，自动聚焦输入框并把光标放到名称末尾，不自动选中文字；新建时也自动聚焦。
- 一次只编辑一个项目；切换到其他项目时放弃尚未提交的编辑，不自动保存。
- 空白名称禁止提交，名称最多 60 字；创建后切换到新项目。
- Enter 提交；Esc 或取消按钮放弃编辑。失焦不自动提交，也不意外丢弃输入。
- 取消后焦点返回对应编辑入口；提交后焦点移到对应项目导航。
- 编辑区域内的按键不触发页面上的新任务或搜索快捷键。
- 输入框、确认和取消按钮都有明确的可访问名称；Tab 可正常离开编辑区，键盘聚焦有可见描边。
- 新建与重命名输入行立即切换，不做高度展开或淡入动画，避免与相邻项目重叠；图标选项保留轻量展开，不增加弹窗。

## 动画规范

使用 [Motion for Vue](https://motion.dev/docs/vue)（`motion-v`），通过 `motion`、`AnimatePresence` 和 `layout` 统一管理动效，不与旧 CSS 入场或 transform 动画叠加。

- 全局默认 200 ms、ease-out，位移控制在 4–12 px 内。
- 首次进入页面时内容轻微淡入；切换项目时标题淡入，侧边栏选中背景平滑移动。
- 列表增删时淡入或收起；拖拽排序时通过布局动画移动位置。添加任务仍是列表内部的最后一行。
- 搜索与图标选项淡入展开；项目新建与重命名输入行立即切换。输入解析提示收起时保持连续过渡。
- 确认、星标、新任务与添加按钮使用轻微按压反馈，不改变图标的布局对齐。
- 撤销 Toast 淡入上移，关闭时淡出；空状态图标只做一次入场，不持续旋转。
- `MotionConfig` 配合 `useReducedMotion` 尊重系统偏好：减少动态效果时跳过组件动画，并关闭 CSS 过渡与启动页旋转。
- 动画不延迟业务操作和输入聚焦，不锁定页面，不增加弹窗。

## 实现与验收

对应实现：`app/components/TheSidebar.vue`、`app/components/ProjectNameEditor.vue` 与 `uno.config.ts`。组件样式由 UnoCSS shortcuts 和状态工具类生成；配置中的 preflight 仅负责主题令牌、基础重置和减少动态效果偏好。

- 新建与重命名共用行内编辑组件，保留现有项目数据接口。
- 删除项目弹窗、遮罩、焦点约束和对应样式，避免两套实现共存。
- 检查浅色、深色、窄屏、长项目名称以及空名称状态。
- 检查自动聚焦、Tab 导航、Enter 提交、Esc 取消及焦点返回。
- 构建与现有项目数据测试通过；不改变任务归属、云同步或时间记录逻辑。


## 日期选择

参考 [TickTick 的快捷日期](https://help.ticktick.com/articles/7055782408586526720)与 [Todoist 的日期标签和日历入口](https://www.todoist.com/help/todoist/features/set-a-task-duration-L1kYkZv8d)，本项目采用以下 Popover 设计：

- 点击到期日期按钮打开 [Reka UI Popover](https://reka-ui.com/docs/components/popover)，浮层锚定按钮，不撑高任务行，不添加遮罩。
- 使用 Portal 避免被任务行裁切；自动翻转和避让视口边缘，浮层最大宽度为视口减 24 px，高度受可用空间约束。
- 常用日期以图标、名称与具体月日组成纵向选项；提供今天、明天、周末、下周一和无日期。
- 宽区域采用快捷选项与月历两列，较窄区域自动堆叠，不挤压日期网格。
- 月历固定六周、周一起始，相邻月份日期低对比但可选择；月份切换不改变网格高度。
- 已选日期使用实色圆形背景，今天只强调文字，避免混淆两种状态。
- 日期网格支持方向键、Home / End、Enter 与 Esc；选择后即保存并关闭，焦点回到日期入口。点击浮层外部也可关闭，由组件库管理焦点恢复。
- 复用 UnoCSS 主题与 Motion 的轻量淡入，日期只作为任务属性，不改变项目分类。
